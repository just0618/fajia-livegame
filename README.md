## 上传到 GitHub

1. 新建公开仓库 `fajia-livegame`。
2. 点击 `Add file → Upload files`。
3. 上传本文件夹中的 `index.html`、`style.css`、`app.js` 和 `README.md`。
4. 打开 `Settings → Pages`。
5. 在 `Build and deployment` 中选择 `Deploy from a branch`。
6. Branch 选择 `main`，文件夹选择 `/ (root)`，点击 `Save`。
7. 发布完成后访问：

```text
https://just0618.github.io/fajia-livegame/
```

## 已上线：法嘉心率实验室

路径：

```text
games/heart-rate-lab/
├── index.html
├── style.css
├── app.js
└── questions.js
```

功能：

- 两种玩法：动作心率实验、对视问答实验
- 两种记录方式：健康数据回看、手表实时观察
- 健康回看模式：
  - 每道题自动同步到下一整分钟开始
  - 每轮实验一分钟
  - 实验后休息一分钟
  - 休息时无需关闭心率测量
  - 只记录实验分钟，休息分钟不会出现在录入列表
  - 全部结束后手动录入对应分钟的最低和最高心率
- 实时观察模式：
  - 手动输入动作前心率
  - 15秒任务计时
  - 手动输入观察到的最高心率
- 动作题库：轻量15题、高心动15题
- 对视问答题库：20题
- 支持3轮和5轮
- 跳过不占正式轮数
- 一局只记录一位佩戴者
- 所有心率数值只在当前页面内临时计算，不连接、不上传健康数据


### 心率实验室 V16：双人同步

- 保留单人反应模式
- 新增双人同步模式：两个人同时佩戴设备
- 双人共同动作使用15道独立对称题目
- 双人共同问答使用15道双方依次回答的问题
- 双人同步仅使用健康数据回看
- 每轮仍为实验一分钟、休息一分钟
- 两个人分别录入同一实验分钟的最低和最高心率
- 结果分别展示法宣阁最高波动、贺嘉述最高波动与共同高反应瞬间
- 共同波动按双方本轮波动值之和计算，仅用于娱乐性排序


### V17：真心话大冒险随机抽卡优化

- 只抽真心话：真心话题库抽完后单独重新洗牌
- 只抽大冒险：大冒险题库抽完后单独重新洗牌
- 随机模式：
  - 真心话和大冒险都有剩余时，继续随机决定题型
  - 真心话先抽完时，自动只抽尚未完成的大冒险
  - 大冒险先抽完时，自动只抽尚未完成的真心话
  - 两类题目都全部出现后，才一起重新洗牌
- “换一张”仍会把当前卡片视为已经出现，不切换玩家


### V18：真心话大冒险跨场进度

- 新增本场题数：5题、10题、15题、全部可用题目
- 默认选择10题
- “全部可用题目”会根据当前题目范围和历史进度动态显示剩余数量
- 默认在当前浏览器保存已展示卡片的稳定编号
- 不保存玩家回答、直播内容或换题原因
- “换一张”不增加正式完成题数，但该卡视为已经展示
- 下次使用同一设备和浏览器时，自动排除历史已展示卡片
- 可清除当前选择范围进度，也可清除全部真心话大冒险进度
- 历史进度关闭时，不读取或写入历史记录，但本场内仍不会重复
- 本场结束后显示完成数、换题数、累计已看和当前剩余
- 当前范围全部完成后不会自动重复，需要清除进度或更换范围

## GAME 07：法嘉别中招挑战

- 双方依次秘密给对方设置一个词语或动作
- 支持自定义目标和随机灵感
- 挑战时长：3分钟、5分钟、10分钟、不限时
- 发现对方中招后，先揭晓目标并由双方确认
- 时间结束或提前结束时判为平局，不进入惩罚
- 中招者可选择：
  - 稳妥路线：直接接受1项惩罚
  - 冒险路线：6张事件卡中2张幸运逃脱、4张双重惩罚
- 冒险失败时抽取2项惩罚：
  - 优先1项专属方向惩罚
  - 1项双向通用惩罚
  - 最多出现1项直播后履约或终极惩罚
- 每项惩罚最多允许换一次
- 公共惩罚库独立保存在 `shared/punishments.js`
- 专属方向题量：
  - 小贺中招：小法→小贺20项
  - 小法中招：小贺→小法19项
- 已删除“额外掷骰子机会”，事件卡只包含幸运逃脱和双重惩罚
