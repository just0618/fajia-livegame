法嘉百分排序挑战怎么玩？

每轮两个人分别担任“描述者”和“排序者”。系统会为A、B、C、D生成4个不同的1—100数字， 只有描述者依次查看。描述者围绕同一个主题，为四个数字各说一个具体例子，但不能直接透露数字； 排序者听完后，把A、B、C、D按数字从小到大排列。

HOW TO PLAY

一轮游戏分为5步

  1. 01
    分配角色

    一人担任描述者，另一人担任排序者。

  2. 02
    排序者避开屏幕

    描述者依次查看A、B、C、D对应的4个隐藏数字。

  3. 03
    按同一主题描述

    描述者为每个标签说一个具体例子，用例子的程度表达数字大小，但不能说出数字。

  4. 04
    从小到大排序

    排序者只根据四个描述，依次点击A、B、C、D完成排列。

  5. 05
    提交并揭晓

    系统公布真实数字和正确顺序；排错时可选择抽取一项轻松惩罚。

假设示例主题是“周末一起做什么最放松”，A=10、B=85、C=40、D=65。 描述者分别为A、B、C、D说一个具体活动；排序者根据“放松程度”判断， 正确顺序应为A → C → D → B。

百分排序挑战规则

  1. 先确定描述者和排序者，排序者暂时不要看屏幕。
  2. 系统随机生成4个不同数字，分别对应A、B、C、D；描述者一次只看一个。
  3. 描述者围绕同一个主题，为每个标签说一个具体例子，用例子的强弱表达数字大小，不能说出数字。
  4. 四个描述全部完成后，排序者按“最小到最大”的顺序点击A、B、C、D。
  5. 提交后公布真实数字和正确顺序；排序错误时可以抽取轻松惩罚，不合适可以换或直接跳过。

例如主题为“喜欢的约会地点”，数字越大代表越喜欢。 描述者可以分别说“便利店门口”“电影院”“海边”“一直想去的城市”， 排序者再根据喜欢程度判断四个标签的先后。网页不会保存描述内容、排序结果或惩罚执行情况。
