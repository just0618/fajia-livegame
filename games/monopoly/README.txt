法嘉直播游戏屋｜法嘉致富大富翁 64格完整版
==========================================

一、已经实现
------------
- 使用原图作为完整棋盘背景
- 按螺旋路线录入0—63共64个格子坐标
- 默认玩家：法宣阁（#FF8AA1）、贺嘉述（#FFE25B）
- 开局现实石头剪刀布，网页手动确认先手
- 双人轮流掷骰子和逐格移动动画
- 普通任务、前进、后退、暂停一回合、再掷一次、终点
- 超过终点时直接到达终点
- 普通任务可标记为“本局跳过”，棋子退回并重新掷骰
- 已跳过格子再次被投中时自动退回重掷
- 可查看、单独恢复或全部恢复已跳过任务格
- 浏览器自动存档
- 手动输入两名玩家位置和下一回合玩家
- 可生成存档码，在另一台设备继续游戏
- 游戏记录、进度条、胜利弹窗和万能任务卡
- 手机与电脑响应式布局
- 64格任务编号表和带编号棋盘
- 棋盘坐标微调工具

二、本地启动
------------
1. 解压文件夹。
2. 在该文件夹打开命令提示符或PowerShell。
3. 运行：
   python -m http.server 8000
4. 浏览器打开：
   http://localhost:8000

任务编号表：
   http://localhost:8000/task-reference.html

坐标微调工具：
   http://localhost:8000/coordinate-helper.html

三、文件说明
------------
index.html
  游戏主页面。

style.css
  页面样式和手机适配。

board-data.js
  64个格子的坐标、任务内容、类型和所需道具。
  以后修改任务文字，主要编辑此文件。

app.js
  掷骰子、棋子移动、回合、跳过任务、存档和读档逻辑。

task-reference.html
  显示带编号棋盘和64格完整清单。

coordinate-helper.html
  点击棋盘重新采集或微调格子坐标。

assets/board.jpg
  原始棋盘背景图。

assets/board-numbered.png
  标注0—63编号的开发参考图。

四、上线
--------
确认本地运行无误后，可以把整个文件夹直接压缩并上传到
Cloudflare Pages Direct Upload。无需Python后端和数据库。

五、说明
--------
原图任务文字已在可辨认范围内尽量逐字录入，不再主动改写任务内容。
如发现个别模糊格子录入有误，可直接在 board-data.js 中修正。

正式公开分享前，请确认棋盘图片的使用授权；也可以后续重新绘制一张
原创棋盘，只要保持相同比例和路线，程序逻辑无需重写。


六、V1.1 修改
-------------
- 普通任务格和特殊格均支持“本局跳过此格并重掷”。
- 跳过前进、后退、暂停一回合或再掷一次格时，会撤销已经产生的特殊效果，
  将棋子恢复到本次掷骰前的位置，并由当前玩家重新掷骰子。
